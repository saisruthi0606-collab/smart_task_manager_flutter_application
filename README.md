# Smart Task Manager – Flutter Application

A simple and efficient **task management mobile application** built using **Flutter**.  

This app helps users organize daily tasks, track progress, and improve productivity through an intuitive user interface.

---

📌 Features

- ➕ Add new tasks  
- ✏️ Edit existing tasks  
- ❌ Delete tasks  
- 📋 View all tasks in an organized list  
- 📱 Clean and responsive UI  
- ⚡ Fast performance using Flutter framework  

---

 🛠️ Tech Stack

- **Frontend:** Flutter  
- **Language:** Dart  
- **IDE:** Android Studio / VS Code

## 🚀 Getting Started

### Prerequisites

- Flutter SDK installed
- 
- Android Studio or VS Code
- 
- Emulator or physical device  

### Steps to Run the Project

1. Clone the repository
   
   git clone https://github.com/saisruthi0606-collab/smart_task_manager_flutter_application.git
   
2/Navigate to the project directory

3.cd smart_task_manager_flutter_application

4.Install dependencies

5.flutter pub get

6.Run the application

7.flutter run
